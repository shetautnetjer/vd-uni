# Sites

This project uses `yt-dlp` for site extraction.

## Default enablement
- YouTube: enabled
- X: enabled (may need cookies)
- Pornhub: disabled by default

## Cookies
If a site requires login, export cookies to `config/cookies.txt` and set `use_cookies: true` in `config/settings.json`.

## Compliance
Only download content you have rights to access and download, and comply with local laws and site terms.
